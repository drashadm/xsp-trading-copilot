# Public examples

Start with the [example classification index](../examples/README.md). Synthetic reports illustrate concepts; they do not prove that production ran a workflow or achieved an outcome.

| Artifact | Purpose | Evidence class |
| --- | --- | --- |
| [Durable outbox reference](../reference/README.md) | Runnable atomic admission, ownership, uncertainty, and terminal behavior | Independently authored educational code and fixture tests |
| [Recommendation](../examples/sample_automatic_contract_recommendation.json) | Suppressed synthetic recommendation with explicit disabled execution | Synthetic illustration; independent of production schema |
| [Point-in-time rehearsal](../examples/point_in_time_rehearsal_sample.md) | Keep a historical decision basis separate from later observations | Historical synthetic illustration |
| [Replay report](../examples/replay_report_sample.md) | Explain evidence quality and missing context | Historical synthetic illustration; no current replay-readiness proof |
| [Alert outbox sample](../examples/alert_outbox_sample.json) | Show older dry-run eligibility and suppression concepts | Historical synthetic schema, not current durable ownership |
| [App state sample](../examples/public_app_state_sample.json) | Show conservative operator posture and disabled execution | Historical synthetic schema, not current UI evidence |

Current production scope belongs in the [evidence register](PUBLIC_PROOF_RELEASE.md). Existing samples contain invented prices, scores, reasons, dates, and timing values. None is a production rule, ranking weight, performance report, API contract, or trading instruction.
